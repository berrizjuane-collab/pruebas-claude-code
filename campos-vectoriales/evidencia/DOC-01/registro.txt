# DOC-01 · Documentación final · 2026-10-03

## 1. Un tercero ejecuta el proyecto siguiendo solo el README

Clon limpio de `main` en un directorio vacío (git clone --depth 1) y, sin nada más que el README:

    cd campos-vectoriales
    node --version                  → v22.22.0 (README: ≥ 22.12)
    npm ci                          → found 0 vulnerabilities
    npm run check                   → lint y tipos sin errores; Tests 419 passed | 3 skipped (422)
    npm run build                   → dist/campos-vectoriales.html · 1.86 MB ·
                                      sha256 c091c977313db26cbc157d52982e4e79dae2dc0028abaf40eb1ebb3ffd4be4ea
                                      (la misma huella que entrega/campos-vectoriales.html)
    npm run dev                     → http://localhost:5173 responde 200 (probado en otro puerto)
    npx playwright test tests/e2e/h1.spec.ts tests/e2e/val02.spec.ts --project=chromium
                                    → 15 passed
                                      (en este entorno, Chromium preinstalado: no hizo falta
                                      `npx playwright install chromium`)
